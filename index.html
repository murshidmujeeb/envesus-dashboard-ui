Key Features

  • Map: CARTO Positron tiles · 60 real Kozhikode bin locations.
  • Route Optimization: Nearest-neighbour heuristic from actual coordinates.
  • Shared State: Collection confirmations update Admin, Staff & Driver views.
  • Reset: Settings → Reset Demo Data to clear all collections.
